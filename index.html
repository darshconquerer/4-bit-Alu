What's happening on the backend

Every calculation is just a circuit on logic gates. The small circuots on the right side of adder and subtractor show how logic gates like AND, OR, XOR and NOT and built using universal NAND gate

Adder

Each stage adds one column of A and B just like using pen paper

  • An XOR of the two input bits give the sum bit (1 + 1 gives 0 here)
  • An AND of the same two bits give the carry
  • A second full adder takes input into its XOR and AND. The half adder inside the full adder takes input from XOR of first half adder and from the carry of first adder on top of the section. The AND gate from both half adders feed into OR gate giving next carry
  • That carry feeds the next stage, so it ripples through all four

The lamps show four sum bits plus final carry, whih can be taken as fifth bit. The biggest case is 15+15 = 30 i.e; 11110, this way we can tackle overflows.

Subtractor

Subtracting circuit is not too different as the rule is A - B = A + NOT(B) + 1

  • A NOT gates flips input B
  • The fixed 1 at the top goes in as first carry(Makes up for operation being 15 - B and not 16 - B)
  • The flipped B and A go through adder stages

The extra lamp(Carry-Over) tells you what happened. ON means A > B, so four bits are the answer. OFF means A < B, so there is a borrow and answer is negative. Then page shows the four bits minus 16.

Multiplier

Binary multiplication is shift and add like we do on paper

  • Each bit of A is fed to AND with B as second input bit. That makes 16 partial products, arranged as four shifted rows
  • The adders below add the four rows together column by column, passing carries along.

Two 4-bits number can make up to 8-bits and the multiplier has lamp for each one, so even 15*15 won't overflow.
